# Actual daily adapter: native TypeScript and clean boundaries
Objective: preserve the Actual CLI contract while moving its daily entry point to ESM TypeScript.
Branch: proposed `refactor/actual-native-typescript`, from `47b95e7` (reconfirm at execution); delivery: `ask-on-risk`, no publish authorized; runners: Node 24.22.3 `node --test`, strict `tsc --noEmit`, `go test ./...`.

## Specs

1. **S1 — Preserve the command contract.** “Mantengamos el CLI y el comportamiento actual” applies to `ynab-expense actual …` and the script's subcommands: arguments and validation order, stdout, stderr, exit codes, initialization, locks/leases, and persisted state. Only the direct script path changes. Characterize with temporary fixtures and normalized nondeterministic values; do not operate on live financial data.
2. **S2 — Native ESM TypeScript and coordinated cutover.** “Arquitectura Limpia y TypeScript nativo sin build”; “no quiero ese puente temporal”. Use `scripts/actual-runtime/actual-daily.ts` on Node 24.22.3 and set `"type": "module"` in the existing runtime package. Check new TS with strict `tsc --noEmit` and erasable syntax. Update Go's default adapter path, the active test references, the runbook and the existing daily Gmail automation in the operational checkout. Keep the `ACTUAL_ADAPTER_PATH` override, scheduler identity/schedule and unrelated prompt rules. Do not ship an `.mjs` compatibility entry, introduce a JS build, change the NVM global default, or start a live reconciliation.
3. **S3 — Migrate only the first read-only use case.** Move `status` behind a typed application boundary. Read the existing state through an injected port, then obtain the Santiago calendar date through an injected clock; return `{state, windows}` including unknown state keys. Keep one pure window policy for both `status` and `begin-run`, with a compatibility export for existing policy consumers as needed. “dejemos las operaciones financieras para después”: keep their implementations, the backup and server LaunchAgents, and historical utilities out of this change.
